## Separate storage from use

Encryption at rest protects a stored representation. Access controls decide who can retrieve or decrypt it. Delivery places the credential where a process needs it, and rotation replaces it without breaking that process. Validate all four separately.

An encrypted Ansible Vault file can still expose plaintext through debug output or a rendered template. A Kubernetes Secret still needs access controls and an appropriate encryption-at-rest configuration. Do not treat a secret-shaped filename or a variable prefix as a protection mechanism.
