Deploy and recover workloads through the actual source owner and compatibility contract.

- [Deploy and verify](/docs/playbooks/operations/gitops/deploy-and-verify): Follow the source revision, rollout, routing, and application behavior.
- [Rollback and recovery](/docs/playbooks/operations/gitops/rollback-and-recovery): Restore a compatible version without assuming data changes reverse automatically.

For a disposable learning exercise before operating an existing environment, follow the
[declarative deployment examples](/docs/infrastructure/gitops/argocd/examples).
