Development playbooks cover repeatable workstation, repository, implementation, testing, and
release procedures. Each procedure should state its prerequisites, consequential choices, proof of
completion, and recovery path.

- [Set up a new Mac](./new-mac) establishes a secure, reproducible development workstation.
- [Next.js basic walkthrough](./nextjs-basics) builds pages, client interaction, and a JSON endpoint.

- [Observability and discovery labs](./observability): learn Prometheus, OpenTelemetry, and Consul locally.

- [Go and React RPC lab](./grpc-go-react): shared Protobuf contract, Buf generation, and browser/native calls.
