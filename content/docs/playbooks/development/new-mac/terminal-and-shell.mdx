Use **iTerm2** as the terminal emulator for this Mac setup, with Zsh as the shell.
The terminal provides windows, tabs, and panes; Zsh runs the commands inside them.

## Install iTerm2

Install the [Homebrew iTerm2 cask](https://formulae.brew.sh/cask/iterm2):

```bash
brew install --cask iterm2
```

Open iTerm2 from Applications and use it for the commands in these playbooks. Configure profiles
for fonts, colors, working directories, and keyboard shortcuts as needed. iTerm2 supports split
panes, search, and optional shell integration; see the
[iTerm2 documentation](https://iterm2.com/documentation.html).

Keep terminal settings separate from `.zshrc` and other shell files. To restore iTerm2 preferences
across Macs, use its custom preferences folder setting and keep the selected folder under the
`config/iterm2/` owner in your dotfiles repository. Review settings before syncing them; see
[General preferences](https://iterm2.com/documentation-preferences-general.html).

## Shell layers

```text
terminal emulator  windows, tabs, rendering, key bindings
zsh                shell language, completion, aliases, functions
prompt             compact repository and runtime context
multiplexer        persistent remote or long-running sessions, when needed
```

Prefer small files sourced from `.zshrc` over one large dump:

```text
~/.config/zsh/
├── aliases.zsh
├── completion.zsh
├── environment.zsh
├── functions/
└── integrations/
```

Measure shell startup before adding a framework. Plugins that run subprocesses on every prompt can
make every terminal feel slow. Keep secrets out of shell files; load them from a password manager
or a scoped secret system.

## Useful baseline tools

```bash
brew install git gh ripgrep fd fzf jq yq bat eza zoxide
```

Install only the commands you use. Learn their unaliased forms first, and avoid aliases that make
destructive commands more aggressive.

Continue with [command history and navigation](/docs/playbooks/development/new-mac/command-history-and-navigation) to configure durable
Zsh history, fuzzy `Control-R` search, contextual Atuin history, and directory jumping with zoxide.
