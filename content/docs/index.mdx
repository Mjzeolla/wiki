## Capture workflow

1. Capture an unfinished idea under [Notes → Inbox](/docs/notes/inbox).
2. Refine chronological context in [Daily notes](/docs/notes/daily).
3. Promote durable material into Knowledge, Playbooks, or the Glossary.
4. Add sources and links so future revisions can distinguish evidence from memory.
