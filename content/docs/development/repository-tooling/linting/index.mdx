---
title: Linting and Quality
description: Static analysis and specialized repository checks that catch defects and policy violations.
---

Use focused tools for focused checks instead of expecting one linter to understand every artifact.

- [ESLint](/docs/development/repository-tooling/linting/eslint) checks JavaScript and TypeScript behavior and conventions.
- [Markdownlint](/docs/development/repository-tooling/linting/markdownlint) checks Markdown structure and style.
- [Additional quality tools](/docs/development/repository-tooling/linting/additional-quality) covers links, shell scripts, workflows, secrets,
  and other repository surfaces.
