---
title: Git Hooks
description: Fast local checks that run around commits and pushes.
---

Hooks shorten the feedback loop, but CI remains authoritative because local hooks can be skipped.

- [Husky](/docs/development/repository-tooling/hooks/husky) fits repositories where Node is already a contributor requirement.
- [pre-commit](/docs/development/repository-tooling/hooks/pre-commit) fits Python-led and multi-language, file-oriented workflows.
