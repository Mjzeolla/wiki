- [Vitest](/docs/development/testing/vitest) runs fast unit and integration tests in Vite-friendly TypeScript projects.
- [Testing Library](/docs/development/testing/testing-library) tests UI behavior through user-observable semantics.
- [Playwright](/docs/development/testing/playwright) verifies critical flows in real browser engines.
- [Testing strategy](/docs/development/testing/strategy) explains how unit, component, integration, contract, browser, and
  smoke tests fit together.
- [Test structure](/docs/development/testing/structure) organizes shared configuration, fixtures, builders, factories,
  fakes, matchers, and environment setup.
- Language guides: [TypeScript and React](/docs/development/testing/typescript), [Python](/docs/development/testing/python), and [Go](/docs/development/testing/go).

Use the lowest test level that proves the behavior. Keep a small number of browser tests for risks
that unit or component tests cannot represent.
