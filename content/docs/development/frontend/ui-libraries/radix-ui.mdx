Radix Primitives provide low-level, unstyled React components for common interactive patterns. They
handle much of the difficult behavior around roles, focus, keyboard navigation, controlled state, and
composition while leaving visual design to the application.

Use Radix when building a custom design system or when native elements do not cover the required
interaction. It works with Tailwind, plain CSS, CSS Modules, and other styling approaches.

Radix is a behavior layer, not a finished visual system. Budget for tokens, component recipes,
responsive states, documentation, visual regression tests, and product compositions. Prefer native
HTML when it already provides the required semantics and interaction.

The primitives improve the starting point for accessibility, but consumers must still provide labels,
descriptions, meaningful content, and application-level testing.
