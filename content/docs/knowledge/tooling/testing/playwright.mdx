## Why use it

Playwright drives real Chromium, Firefox, and WebKit browsers with automatic waiting, isolated
contexts, tracing, screenshots, and network controls.

## Use it when

- a critical user flow crosses routing, browser APIs, authentication, or a real backend;
- behavior must be verified across browser engines; or
- failures need reproducible traces and visual evidence.

## Avoid or limit it when

Browser suites cost more to run and debug. Keep them focused on high-value flows and use unit or
component tests for logic that does not require a browser.

## How to start using it

Install the test runner in a TypeScript web application:

```bash
pnpm add --save-dev @playwright/test
pnpm exec playwright install
```

The browser install is separate from the package install because each Playwright release expects
matching browser binaries. In Linux CI, `playwright install --with-deps chromium` can install one
browser and its operating-system dependencies.

Keep browser tests outside application source:

```text
e2e/
├── authentication.spec.ts
├── navigation.spec.ts
└── support/
    └── fixtures.ts
playwright.config.ts
```

Configure the running application, CI retries, and failure evidence:

```ts
import { defineConfig, devices } from '@playwright/test';

export default defineConfig({
  testDir: './e2e',
  retries: process.env.CI ? 2 : 0,
  use: {
    baseURL: 'http://127.0.0.1:3000',
    trace: 'on-first-retry',
    screenshot: 'only-on-failure',
  },
  webServer: {
    command: 'pnpm start',
    url: 'http://127.0.0.1:3000',
    reuseExistingServer: !process.env.CI,
  },
  projects: [{ name: 'chromium', use: { ...devices['Desktop Chrome'] } }],
});
```

Write tests against accessible roles and user-visible behavior:

```ts
import { expect, test } from '@playwright/test';

test('opens the documentation', async ({ page }) => {
  await page.goto('/');
  await page.getByRole('link', { name: 'Documentation' }).click();
  await expect(page.getByRole('heading', { name: 'Documentation' })).toBeVisible();
});
```

Useful commands:

```bash
pnpm exec playwright test
pnpm exec playwright test --ui
pnpm exec playwright test --debug
pnpm exec playwright show-report
```

Start with Chromium and a few critical paths. Add Firefox, WebKit, mobile emulation, or a larger
matrix only when browser-specific risk justifies the runtime.
