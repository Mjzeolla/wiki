AI helpers are most useful when selected for a measured bottleneck. Adding every helper increases
permissions, installation work, context routing, and maintenance.

- [RTK](./rtk) compresses noisy shell output before it reaches the model.
- [Helper selection](./helpers) compares repository packing, semantic navigation, current library
  documentation, structural search, and cross-repository search.
