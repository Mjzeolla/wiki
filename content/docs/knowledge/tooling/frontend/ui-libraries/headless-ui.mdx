Headless UI provides unstyled, accessible interactive components for React and Vue and is designed to
integrate closely with Tailwind CSS.

Choose it when the product already uses Tailwind, wants to own all visual decisions, and its component
needs fit the library's focused catalog. It is especially useful for patterns such as dialogs, menus,
popovers, tabs, comboboxes, listboxes, and switches.

Compare the actual catalog against the roadmap before adopting it as the only primitive layer. A
smaller API is an advantage when it covers the product, but it can lead to inconsistent one-off
implementations if the application soon needs primitives outside that scope.
