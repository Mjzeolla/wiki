React Aria supplies unstyled components and lower-level hooks with accessibility, interaction, and
internationalization behavior built in. Its components can be styled with Tailwind, plain CSS, or
another styling solution.

Use it when the product must work well across keyboards, pointers, touch, screen readers, locales, and
complex interaction states. Start with React Aria Components; drop to hooks only when the component API
cannot provide the required control.

React Aria is different from React Spectrum: React Aria is the unstyled behavior layer, while React
Spectrum applies Adobe's design system. Do not adopt the styled system accidentally when the product
only needs accessible primitives.
